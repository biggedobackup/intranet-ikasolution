Liste SharePoint : Actualites
===============================

Champs à créer dans la liste :

1. Titre (Title)
   - Type : Ligne de texte
   - Requis : Oui

2. Description
   - Type : Texte multiligne
   - Requis : Oui

3. Catégorie
   - Type : Choix (Institution, Projet, Vie de l'entreprise, Ressources Humaines, ...)
   - Requis : Oui

4. Date de publication
   - Type : Date et heure
   - Requis : Oui

5. Auteur
   - Type : Ligne de texte
   - Requis : Non

6. Images
   - Type : Texte multiligne (JSON {"fileName":"..."})
   - Requis : Non

7. Active
   - Type : Oui/Non
   - Requis : Oui
