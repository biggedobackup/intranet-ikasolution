Liste SharePoint : Evenements
===============================

Champs à créer dans la liste :

1. Titre (Title)
   - Type : Ligne de texte
   - Requis : Oui

2. Description
   - Type : Texte multiligne
   - Requis : Oui

3. Date et heure de début
   - Type : Date et heure
   - Requis : Oui

4. Date et heure de fin
   - Type : Date et heure
   - Requis : Non

5. Localisation
   - Type : Ligne de texte
   - Requis : Oui

6. Catégorie
   - Type : Choix (Séminaire, Workshop, Team Building, ...)
   - Requis : Oui

7. Images
   - Type : Texte multiligne (JSON {"fileName":"..."})
   - Requis : Non

8. Active
   - Type : Oui/Non
   - Requis : Oui
