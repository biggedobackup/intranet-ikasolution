Liste SharePoint : Signalements Absence
===============================

Champs à créer dans la liste :

1. Titre (Title)
   - Type : Ligne de texte
   - Requis : Oui

2. Demandeur
   - Type : Personne ou groupe
   - Requis : Oui

3. TypeAbsence
   - Type : Choix (Maladie, Autorisée, Imprévue, Rendez-vous)
   - Requis : Oui

4. DateDebut
   - Type : Date
   - Requis : Oui

5. DateFin
   - Type : Date
   - Requis : Oui

6. Motif
   - Type : Texte multiligne
   - Requis : Oui

7. Validateur
   - Type : Personne ou groupe
   - Requis : Non
   - Usage : Personne en charge de la validation du signalement

8. Statut
   - Type : Choix (En attente, Approuvé, Refusé, Annulé)
   - Requis : Oui

9. CommentaireDecision
   - Type : Texte multiligne
   - Requis : Non
   - Usage : Commentaire du validateur lors de la validation ou du rejet

10. DateDecision
   - Type : Date
   - Requis : Non
   - Usage : Date à laquelle le signalement a été validé ou rejeté

11. Active
   - Type : Oui/Non
   - Requis : Oui
